# 사이트 설계도(PRD) — (미정)

작성일: 2026-10-11 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
가게·온라인 판매·개인 브랜드에 필요한 디자인을 혼자 맡아 만들어 드리는 1인 디자인 대행 서비스.

## 2. 손님
- 누가: 소상공인 사장님 · 온라인 셀러 · 개인 브랜드·강사
- 어디서 알고 오나: 인스타그램 · 검색 · 지인 소개 · 크몽·숨고

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격
2. 작업 기간
3. 포트폴리오
4. 수정 횟수

## 4. 믿게 할 증거 (실제로 있는 것만)
- 아직 없음 — 포트폴리오 자리만 만들어 두고 "준비 중"으로 둔다
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 문의하기 버튼
2. 이런 분께 — 소상공인 사장님 · 온라인 셀러 · 개인 브랜드·강사
3. 진행 안내 — 가격 · 작업 기간 · 수정 횟수 (지금은 "문의 주시면 안내드려요")
4. 포트폴리오 자리 (준비 중)
5. 후기 자리 (비워 둠)
6. 문의 폼 + 카카오톡 채널 버튼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 문의 내용 (자유롭게)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 작업 기간: (미정)
- 수정 횟수: (미정)
- 위치: (해당 없음 — 온라인 작업)
- 연락 방법: 사이트 문의 폼 · 카카오톡 채널 (채널 주소: 미정)

## 9. 이번에 넣지 않을 것
- 결제
- 회원가입
- 블로그
- 파일 올리기

## 10. 첫 화면 한 문장 후보
1. 가게와 브랜드에 필요한 디자인, 혼자서도 맡길 수 있게.
2. 로고부터 상세페이지까지, 한 사람이 끝까지 맡아 만들어요.
3. 사장님은 장사에, 디자인은 저에게 맡겨 주세요.

## 11. 다음에 할 것
- 사이트 이름 정하기
- 가격 · 작업 기간 · 수정 횟수 정해서 8번에 채우기
- 포트폴리오 작품 모으기
- 실제 후기가 생기면 후기 자리 채우기
- 카카오톡 채널 주소 받기
- 9번 목록(결제, 회원가입, 블로그, 파일 올리기) 중 필요한 것

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: superdesign.dev 라이브러리의 Swiss Style — 분위기만 참고(검은 격자선, 굵은 글자, 포인트 색 하나), 그대로 베끼지 않음
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
